# Code of Conduct

This project expects all contributors and participants (in Issues, Discussions, and Pull Requests) to:

- Communicate respectfully and assume good faith.
- Focus criticism on code, ideas, and technical tradeoffs, not people.
- Accept that maintainers may close or request changes to contributions that do not fit the project's scope, security constraints, or Manifest V3 requirements.
- Refrain from harassment, discriminatory language, or personal attacks of any kind.

Reports of unacceptable behavior can be filed as a GitHub Issue tagged `conduct`, or sent directly to the repository owner. Maintainers may warn, temporarily restrict, or permanently block contributors who violate these expectations.
